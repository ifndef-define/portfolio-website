Embedded Pac-Man on Spartan-7

FPGA Embedded Graphics

The Challenge

How do you build a graphics engine for a game on an FPGA? Most of my experience was low-level embedded systems. This project pushed me to think about hardware acceleration, memory bandwidth, and rendering pipelines. The goal was to implement real-time graphics output while maintaining game logic responsiveness.

What I Built

A hardware/software co-design using MicroBlaze processor, AXI4-Lite interconnect, shared memory subsystem, and custom RTL rendering logic. The FPGA handled VGA signal generation and display synchronization while the processor managed game logic.

Key Components:

  • MicroBlaze Soft Processor: Managed game state, collision detection, and AI logic
  • AXI4-Lite Interconnect: Connected processor to peripheral modules with predictable latency
  • Custom Rendering RTL: Direct memory access to framebuffer with pipelined output
  • VGA Controller: Timing generation and signal synthesis for 640×480 @ 60Hz output
  • FIFO Buffers: Decoupled processor writes from rendering pipeline reads

Key Learnings

Understanding memory hierarchy, timing constraints, and how to partition work between software and hardware. Learned the importance of synchronization between clock domains and how FIFOs can decouple processor from rendering pipelines.

Technical Insights:

  • Memory Hierarchy: BRAM vs. DDR tradeoffs for buffer size and latency
  • Clock Domain Crossing: Synchronizers needed for safe signal handoff between clock domains
  • Hardware/Software Partitioning: Graphics pipeline benefits more from hardware acceleration than game logic
  • Real-time Constraints: Deterministic pipeline timing enabled predictable frame rates
  • Debugging Embedded Systems: Logic analyzers essential for verifying HW/SW interfaces

Results & Takeaways

Successfully implemented a fully-functional Pac-Man game running at 60 FPS on the Spartan-7 FPGA. The project demonstrated how proper hardware/software co-design can achieve real-time performance while keeping power consumption reasonable. This experience shaped my approach to embedded systems: understanding when to use hardware acceleration versus software flexibility is crucial.

Tech Stack

FPGA Platform: Spartan-7 (XC7A35T)
HDL: SystemVerilog, Xilinx IP (MicroBlaze, AXI)
Tools: Vivado Design Suite, Vivado HLS
Firmware: C/C++ (compiled to MicroBlaze ISA)
Debugging: Vivado Debug Hub, Logic Analyzer
